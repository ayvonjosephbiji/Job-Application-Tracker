# Job-Application-Tracker

Features included:

✅ Add, edit, and delete applications
✅ Full job details/description field
✅ Track interview dates, times, and formats
✅ Personal notes section
✅ Follow-up reminders
✅ Status tracking (Applied, Waiting, Interview, Offer, Rejected)
✅ Dashboard with live stats
✅ Search and filter capabilities
✅ Dark tech aesthetic (perfect for IT/cybersecurity)
✅ Local storage - your data persists even after you close the browser!
